# Kinmetrix prototype (React)

Vite + React + TypeScript app for greenfield tablet UX work.

## Commands

```bash
yarn          # install
yarn dev      # dev server (default http://127.0.0.1:5173)
yarn build    # production build
yarn preview  # preview production build
```

## Repo context

Kinmetrix IA, OOUX, and the static demo live under `../downloads/` (read-only for agents). Start from `../downloads/kinmetrix-tablet/ia-handoff.md` when shaping navigation and objects.

## Verification

Agents should use the project skill `.cursor/skills/verify-kinmetrix-prototype/` at the repo root to launch, drive, and capture proof.
