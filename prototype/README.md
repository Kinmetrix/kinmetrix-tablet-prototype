# Tablet HTML prototype

Self-contained Kinmetrix clinic iPad walkthrough. No external app checkout required.

```bash
yarn install
yarn dev
```

Open [http://localhost:5173](http://localhost:5173).

Start with **`docs/product.md`**, then **`docs/glossary.md`**, **`docs/journeys.md`**, **`docs/personas.md`**, **`docs/placeholders.md`**, and **`docs/screen-inventory.md`**.
