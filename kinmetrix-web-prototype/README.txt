KINMETRIX INTERACTIVE PROTOTYPE

1. Open index.html in a browser (phone or desktop).
2. Optional query params: ?scenario=first|empty|one|history and ?theme=light|dark
   (defaults: first scenario, dark theme; theme is remembered in localStorage).

Everything needed is inside index.html. No installation or server is required.
The prototype uses sample data. Account creation, sign-in, contact verification,
location emails and device connections are simulated. No messages are sent.

Demo codes:
- Screen code: 482716
- Contact verification: 123456

Tap through the flows in the UI. Demo codes below unlock sign-in and device paths.
Reload the page to return to the starting scenario.

Kinmetrix is planned as a web app. This prototype is the phone-width experience first;
a responsive layout for larger screens is future work.

The HTML contains the editable styles, screen markup and JavaScript.
